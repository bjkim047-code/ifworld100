# 세계가 100명이라면 (ifworld100)

"80억 지구, 만약 세계가 100명이라면?" 생각 열기 문제 10개를 학생들이 웹페이지에서
한 문제씩 풀고, 답과 점수가 구글 시트에 자동으로 기록되는 웹앱입니다.

- 학번·이름을 입력하고 접속 → 한 문제씩 풀기 → 마지막에 답 확인 후 제출
- 채점은 서버(Apps Script)에서 하므로 학생 화면에는 정답이 노출되지 않습니다.
- 시트 `제출` 탭에 `제출 시각 | 학번 | 이름 | 1~10번 점수 | 합계 | 1~10번 답`이 한 줄씩 쌓입니다.
- 같은 학번은 한 번만 제출할 수 있습니다 (다시 풀게 하려면 시트에서 그 학생의 줄을 지우면 됩니다).
- 풀던 중 새로고침해도 같은 기기에서는 입력한 답이 남아 있습니다.

## 설치 방법 (약 5분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. (예: `세계가 100명이라면 - 제출`)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 이 저장소의 `apps-script` 폴더 파일을 같은 이름으로 넣습니다.
   - 기본으로 있는 `Code.gs` 내용을 지우고 `Code.gs` 내용을 붙여넣기
   - `+` → **스크립트** → 이름 `Scoring` → `Scoring.gs` 내용 붙여넣기
   - `+` → **HTML** → 이름 `Index` → `Index.html` 내용 붙여넣기
4. 💾 저장 후, 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(⚙️): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 승인(내 구글 계정 선택 → 고급 → 안전하지 않은 페이지로 이동 → 허용)
5. 나오는 **웹 앱 URL**을 학생들에게 공유합니다 (QR 코드로 만들어 칠판에 띄우면 편합니다).

코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 학생 화면에 반영됩니다.
(URL은 그대로 유지됩니다.)

## 설정 바꾸기 (`Code.gs` 맨 위)

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| `SHOW_ANSWERS_AFTER_SUBMIT` | `false` | `true`면 제출 후 학생 화면에 문항별 정답도 보여줍니다. |
| `BLOCK_DUPLICATE_SUBMISSION` | `true` | `false`면 같은 학번도 여러 번 제출할 수 있습니다. |

## 채점 규칙 (`Scoring.gs`)

문항당 10점, 총 100점. "10% 단위 감점"은 정답과의 차이가 정답의 10% 이내면 1단계,
20% 이내면 2단계 … 로 계산합니다 (최소 0점).

| 문항 | 정답 | 점수 |
| --- | --- | --- |
| 1. 65세 이상 노인 | 10명 | 10점, 10%마다 2점 감점 (9·11명 8점, 8·12명 6점 …) |
| 2. 가장 많이 사는 대륙 | 아시아 / 60명 | 대륙 5점 + 인원 5점(10%마다 1점 감점) |
| 3. 두 번째로 많이 믿는 종교 | 이슬람(교) / 25명 | 종교 5점 + 인원 5점(10%마다 1점 감점) |
| 4. 글을 읽고 쓸 수 있는 사람 | 66명 | 10점, 10%마다 2점 감점 |
| 5. 가장 많이 사용되는 언어 | 중국(어) / 12명 | 언어 5점 + 인원 5점(10%마다 1점 감점) |
| 6. 극심한 빈곤 | 10명 | 10점, 10%마다 2점 감점 |
| 7. 전쟁에 노출 | 10명 | 10점, 10%마다 2점 감점 |
| 8. 아동 노동자 | 2명 | 0명 6, 1명 8, 2명 10, 3명 8, 4명 6, 5명 4, 6명 2, 그 외 0 |
| 9. 기후 변화에 취약 | 40~44명 | 범위 안 10점, 밖이면 가까운 경계(40 또는 44) 기준 10%마다 2점 감점 |
| 10. 말라리아 감염(연간) | 3~4명 | 1명 6, 2명 8, 3~4명 10, 5명 8, 6명 6, 7명 4, 8명 2, 그 외 0 |

글자 답은 띄어쓰기·문장부호를 무시하고 비교합니다 (예: `아시아 대륙`, `아시아대륙`도 정답).
